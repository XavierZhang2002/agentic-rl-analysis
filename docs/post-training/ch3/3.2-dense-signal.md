# 3.2 免 Critic 的稠密信号

!!! abstract "本节摘要"
    VAPO 路线证明了 token 级价值信号的收益，但 Critic 的显存、冷启动与工程成本在大 MoE 上难以承受。2026 年出现两条不训练 Critic 的替代路径：Progress Advantage 用 $\log(\pi_\theta/\pi_{\text{ref}})$ 直接恢复 advantage；SDPO 族用"看到特权上下文"与"没看到"两种条件下的自蒸馏得到 token 级梯度。本节比较三条路线的成本与风险，并说明 Critic 从"唯一解"变成"一种解"。

!!! note "与 2.4 VAPO 的关系"
    [2.4 VAPO](../ch2/2.4-vapo.md) 的结论是：Value-Based 在长 CoT 上有不可替代的优势，代价是 Critic 与三件套修复。本节把它从"Critic 不可替代"改成"Critic 是一条路线，不是唯一路线"：2026 年出现了两条成本远低于 Critic 的替代路径。

---

## 一、Critic 为什么贵

VAPO 用 Critic 拿到 token 级 GAE，代价是三重的：

- **参数量** +25–50%（与 actor 同规模）；
- 需要 **Value Pretraining + Decoupled GAE + Length-Adaptive GAE** 三件套才训得动（2.4 的消融：去掉 Value Pretraining，AIME 2024 从 60 掉到 11）；
- 671B 级 MoE 上工程不可行——显存、通信、冷启动都放不下。

于是问题变成：**不训练 Critic，能不能拿到 token 级信号？** 两条路线分别用"策略自身的概率变化"与"同一模型的特权条件"回答。

## 二、路径一：概率比（Progress Advantage）

**论文**：*Neglected Free Lunch from Post-training: Progress Advantage for LLM Agents*（[arXiv:2606.26080](https://arxiv.org/abs/2606.26080)，NeurIPS 2026）

核心结论：在策略 $\pi_\theta$ 与参考策略 $\pi_{\text{ref}}$ 之间，**token 级 log-prob 比率本身就能恢复最优 advantage**：

$$
\hat{A}^{\text{prog}}_t \;\propto\; \log \frac{\pi_\theta(y_t \mid s_t)}{\pi_{\text{ref}}(y_t \mid s_t)}
$$

机制来自 KL 正则目标的恒等式：最优策略满足 $\pi^\star \propto \pi_{\text{ref}} \exp(A^\star/\beta)$，取对数即 $A^\star \propto \log(\pi^\star/\pi_{\text{ref}})$；用当前策略 $\pi_\theta$ 代替 $\pi^\star$，就得到一个免费的逐 token 打分器。不需要 PRM、不需要 Critic——**只要有一个参考策略**。

- 参考策略可以是 SFT 模型、上一轮 checkpoint，或同批次的其他 rollout；
- 代价：$\pi_{\text{ref}}$ 的选择决定信号质量，"精确恢复"也依赖策略与参考策略的可比性；
- 适用：agent 多步任务——每一步都有 token 分布偏移，天然产生信号；
- 工程前提：$\pi_{\text{ref}}$ 的 logprob 必须与训练侧同源（同一 token 流、同一量化），否则比率里混入训推偏差，见 [4.3](../ch4/4.3-infra-consistency.md)。

## 三、路径二：特权上下文自蒸馏（SDPO / SDAR）

**SDPO**（[arXiv:2601.20802](https://arxiv.org/abs/2601.20802)，ICML 2026）把"反馈 / 答案 / 工具返回"等**特权上下文** $c_{\text{priv}}$ 作为教师信号，让模型在"看到"与"没看到"两种条件下做自蒸馏：

$$
\mathcal{L}_{\text{SDPO}} = \mathrm{KL}\!\left(\pi_\theta(\cdot \mid x, c_{\text{priv}}) \,\Big\|\, \pi_\theta(\cdot \mid x)\right)
$$

学生与教师是**同一个模型**，只差特权信息，因此不需要额外奖励模型或 Critic，却能得到 token 级稠密梯度。SDPO 是 2026 年被引最高的 RL 论文之一（466 引，ICML 2026）。

- **SDAR**（[arXiv:2605.15155](https://arxiv.org/abs/2605.15155)）把它作为门控辅助目标，RL 为主干、自蒸馏只补稠密梯度；
- 风险在特权信息本身：答案或工具返回有噪声时，教师会把错误"教"给学生；若特权上下文里直接含最终答案，模型可能学会抄答案而不是学会推理。

## 四、三条路线的成本对比

| 路线 | 额外模型 | 信号粒度 | 主要风险 |
|---|---|---|---|
| Critic（VAPO） | 与 actor 同规模 | token 级 GAE | 显存 +25–50%，冷启动难 |
| 概率比（Progress Advantage） | 仅参考策略 | step 级 | 参考策略选择敏感 |
| 自蒸馏（SDPO） | 无（同模型双条件） | token 级 | 特权信息必须可靠 |

!!! success "结论"
    "Critic 规模化困境"的解法不是"把 Critic 做小"，而是**换一种免费的信号源**。三条路线不互斥：小模型上 Critic 仍最准，大 MoE 上概率比 / 自蒸馏更现实；SDAR 已经给出"自蒸馏做辅助、RL 做主干"的组合形态。

## 五、怎么选

| 场景 | 首选 | 理由 |
|---|---|---|
| 小模型、单机、短 CoT | Critic（VAPO） | 信号最准，且已有成熟的 PPO 实现 |
| 大 MoE、显存放不下 Critic | 概率比 | 只需一份参考策略的 logprob |
| 有可靠答案或工具返回 | 自蒸馏（SDPO） | 同一模型、两个条件，token 级梯度 |
| RL 主干不能动、只补稠密项 | SDAR | 门控辅助目标，不替换主损失 |

真正的差别在**特权信息的供给质量**：答案 / 工具返回越可靠，自蒸馏越划算；若这条信息通道不可靠，概率比更实际——它不要求额外信息，只要求一个可比的参考分布。

## 开放问题

1. **参考策略的选择**：Progress Advantage 对 $\pi_{\text{ref}}$ 敏感，是否存在"自适应参考"的稳定做法？
2. **概率比的精确性边界**：温度、训推引擎的 logprob 偏差、off-policy 样本下，这个恒等式还成立吗？（一致性问题见 [4.3](../ch4/4.3-infra-consistency.md)）
3. **特权信息的可靠性**：答案有错、工具返回有噪声时，自蒸馏会不会把错误固化进策略？
4. **组合的边界**：Critic + 概率比 + 自蒸馏能否统一成一个"信号源 × 成本"的选择框架？
