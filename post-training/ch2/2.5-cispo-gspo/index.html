    2.5 CISPO 与 GSPO：从裁权重到序列级¶

    本节摘要

    GRPO 的 token 级重要性比率有两个独立病灶：硬裁剪让稀有 token 的梯度在第 1 轮 off-policy 更新后就归零；MoE 上则让比率被路由噪声污染，失去物理意义。CISPO（MiniMax-M1）与 GSPO（Qwen）分别给出两条修法——裁 IS 权重而不裁目标，以及把 IS 粒度抬到序列几何平均。本节把这两条支线并成一页，并说明 GSPO 之后真正止住问题的是基础设施层的路由回放与训推一致性。

    一、问题的两条支线¶

    两条支线的共同起点是同一个 token 级比率：

    \[ r_{i,t}(\theta) = \frac{\pi_\theta(o_{i,t} \mid q, o_{i,<t})}{\pi_{\theta_{\text{old}}}(o_{i,t} \mid q, o_{i,<t})} \]

    PPO/GRPO 把它塞进带 clip 的目标 \(\min(r\hat{A}, \text{clip}(r)\hat{A})\)，于是长出两个互不相关的毛病：

    病灶 触发条件 后果 修法
    梯度被裁掉 分岔词（"However"/"Wait"）初始概率低，\(r\) 很快越过 \(1+\varepsilon\) 该 token 梯度恒为 0，剩余 off-policy 轮次完全学不到 CISPO：裁权重
    MoE 上失效 专家路由在 \(\pi_{\theta_{\text{old}}}\) 与 \(\pi_\theta\) 之间翻盘 ratio 分子分母走了不同子网络，比值不再代表策略偏移 GSPO：序列级 ratio

    前者是"裁得太狠"，后者是"量得不准"。梯度归零的逐项推导见 2.2 GRPO，非对称裁剪的动机见 2.3 DAPO。

    二、CISPO：裁 IS 权重而不是目标¶

    CISPO 出自 MiniMax-M1 技术报告（MiniMax，2025，arXiv:2506.13585），首次把 clip 从目标函数挪到 IS 权重上：

    \[ \mathcal{J}_{\text{CISPO}}(\theta) = \mathbb{E} \left[ \frac{1}{\sum_{i=1}^{G}|o_i|} \sum_{i=1}^{G} \sum_{t=1}^{|o_i|} \text{sg}\!\left(\hat{r}_{i,t}(\theta)\right) \cdot \hat{A}_{i,t} \cdot \log \pi_\theta(o_{i,t} \mid q, o_{i,<t}) \right] \]

    其中 \(\hat{r}_{i,t}(\theta) = \text{clip}\!\left(r_{i,t}(\theta),\; 1 - \varepsilon_{\text{low}}^{\text{IS}},\; 1 + \varepsilon_{\text{high}}^{\text{IS}}\right)\)，\(\text{sg}(\cdot)\) 是 stop-gradient；归一化用 \(\sum_i |o_i|\)（token-level），与 DAPO 的全局 token 归一化一致。

    为什么梯度不归零：被裁剪的 \(\hat{r}\) 经 \(\text{sg}()\) 变成常数标量，只当权重；真正可微的是 \(\log \pi_\theta\)，它恒存在：

    \[ \nabla_\theta \mathcal{J}_{\text{CISPO}} \propto \sum_{i,t} \underbrace{\text{sg}(\hat{r}_{i,t})}_{\text{裁剪后的标量权重}} \cdot \hat{A}_{i,t} \cdot \underbrace{\nabla_\theta \log \pi_\theta(o_{i,t} \mid \cdots)}_{\text{始终有梯度}} \]
    算法 裁剪对象 被裁剪 token 的梯度
    PPO / GRPO 目标函数 \(r \cdot \hat{A}\) = 0（完全丢失）
    CISPO IS 权重 \(r\)（在 sg 内） ≠ 0（权重被限制，梯度保留）

    代价是理论保证变弱：越界 token 仍在更新，只是步长被压成常数权重——用权重衰减代替硬停。在 MiniMax-M1 的设置中（每 batch 16 轮 off-policy 更新），分岔词在硬裁剪下第 1 轮就被裁出局，剩余 15 轮没有梯度；CISPO 侧则一直保有一个被压小的更新量。

    三、GSPO：序列级 ratio¶

    GSPO 出自 Group Sequence Policy Optimization（Qwen Team，2025，arXiv:2507.18071），把优化单元从 token 抬到序列：

    \[ \mathcal{J}_{\text{GSPO}}(\theta) = \mathbb{E} \left[ \frac{1}{G} \sum_{i=1}^{G} \min\!\left( s_i(\theta)\, \hat{A}_i,\; \text{clip}\!\left(s_i(\theta),\, 1\!-\!\varepsilon,\, 1\!+\!\varepsilon\right) \hat{A}_i \right) \right] \]

    序列级比率取逐 token 比率的几何平均：

    \[ s_i(\theta) = \left(\frac{\pi_\theta(y_i \mid q)}{\pi_{\theta_{\text{old}}}(y_i \mid q)}\right)^{1/|y_i|} = \exp\!\left(\frac{1}{|y_i|} \sum_{t=1}^{|y_i|} \log \frac{\pi_\theta(y_{i,t} \mid q, y_{i,<t})}{\pi_{\theta_{\text{old}}}(y_{i,t} \mid q, y_{i,<t})}\right) \]

    几何平均不是装饰：每个 token 的路由噪声近似零均值独立，平均后按 \(O(1/\sqrt{|y_i|})\) 衰减，序列越长越稳——与 token-level 的行为相反。同时 IS 粒度终于与 reward 粒度对齐：一个序列级标量奖励对应一个序列级 ratio，不再"1 个信号摊到 N 个 token，噪声却 ×N"。

    与 GRPO 的梯度差别只有一句：GRPO 内同一条序列的不同 token 拿不同权重 \(w_{i,t}\)，GSPO 内整条序列共享同一权重 \(s_i\)。token 间的不一致消失，个别 token 的专家切换也无法单独污染梯度。

    与 CISPO 的分工也由此清楚：CISPO 仍相信 token 级细粒度，只把裁剪对象换掉；GSPO 直接否认这个细粒度的价值——除非 reward 本身是 token 级（过程奖励、PRM），否则把 1 个序列级奖励摊到 N 个 token 只是把噪声放大 N 倍。

    极小裁剪范围是这套设计的直接后果——\(s_i\) 的数值范围比 token-level 紧凑得多：

    \[ \varepsilon_{\text{left}} = 3 \times 10^{-4}, \qquad \varepsilon_{\text{right}} = 4 \times 10^{-4} \]

    对比 GRPO/DAPO 的 \(0.2 \sim 0.28\)，差三个数量级。clip 因此重新是"trust region 围栏"，而不是噪声场里的随机过滤。工程上切一行配置即可：TRL ≥ 0.20 的 importance_sampling_level="sequence"。

    四、MoE 为什么难¶

    MoE 把 dense 模型不存在的失稳因子叠加进 RL。GSPO 论文（§5）与 AReaL / ROLL / TRL ≥ 0.20 的工程实践在三点上一致：

    ① 路由波动。每层 gating 选 top-k 专家（Qwen3-MoE 量级激活率约 10%），参数更新后 gating logits 的微小变化就足以让离散选择整体翻盘：

    \[ \underbrace{\text{argtopk}\big(\text{Gate}_{\theta_{\text{old}}}(h_t)\big)}_{\text{rollout 走的专家集合}} \;\neq\; \underbrace{\text{argtopk}\big(\text{Gate}_{\theta}(h_t)\big)}_{\text{反向走的专家集合}} \]

    后果：同一条响应在 \(\pi_{\theta_{\text{old}}}\) 与 \(\pi_\theta\) 下前向穿过的是不同物理子网络，等于拿两个模型算 ratio。

    ② IS 被污染。token-level ratio 的分子分母走不同专家组合，\(r_{i,t}\) 的波动里绝大部分是路由噪声而非策略偏移——IS 的数学前提（同一支撑集上的相对概率）在 token-level + MoE 下不成立。

    ③ clip 失效。成千上万个 token ratio 各自在 \([1-\varepsilon, 1+\varepsilon]\) 边界抖动：clip 从 trust region 围栏退化成噪声场里的随机过滤，噪声沿响应长度累积，长 CoT / 长 trajectory 上越长越爆，最终 entropy 坍塌或 reward 反向。

    GSPO 论文 §3

    "the instability of GRPO stems from the fundamental misapplication and invalidation of importance sampling weights ... high-variance training noise that progressively accumulates with increased response length and is further amplified by the clipping mechanism."

    五、GSPO 之后的修正¶

    序列级 ratio 只是算法层的补丁。2026 年的结论是一致性优先于目标函数，修正集中在这一层：

    修正 做法 公开证据
    R3 路由回放 在 rollout 阶段（vLLM/SGLang）录下真实 expert indices，强制 recompute 与 update 阶段重放同一套路由（arXiv:2510.11370，ICML 2026） Qwen3-30B-A3B + GRPO：无 replay 62.23 → R3 71.83，KL 降约 2×，collapse 消失
    确定性算子 + 冻结子模块 GLM-5 发现 DSA 的 k=2048 top-k 无法回放，只能把非确定性 top-k 改成确定性实现，并冻结相关子模块 同一 token 两次前向走同一组专家，路由不再需要 replay
    全流程 QAT Kimi K3 用 MXFP4 权重 / MXFP8 激活贯穿 SFT 与 RL；TRACE（2610.07767）用 rollout 侧真实量化结果反向指导训练侧舍入 TRACE rollout 最高 5.4×

    R2 与 R3 的差别只在录制点：R2 录训练引擎 recompute 阶段的路由（解决引擎内部抖动），R3 录 rollout 阶段推理引擎的真实路由（解决跨引擎抖动）——R3 多拿到的那部分，正是 vLLM ↔ Megatron 的差距。

    R3 与 GSPO 是互补而非替代：算法层用几何平均把路由噪声摊平，infra 层把路由直接锁死，verl / ms-swift 已支持 GSPO + R3 组合。逐条机制与五个框架的对比见 4.3 基础设施与一致性。

    GSPO 也不是终点。 它仍在"约束 token 级或序列级 ratio"这一族里换粒度；2026 年的 DPPO 换成直接约束散度、TRM 换成序列级 mask、LPO 换成 listwise 投影、OTB 干脆不改约束只压方差——四条线各自打在 GSPO 的一个隐含假设上，见 2.7 信任域与目标函数的新解法。全部算法的公式速查见 附录 A。
