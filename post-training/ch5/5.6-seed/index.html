    5.6 Seed¶

    本节摘要

    Seed 系列的贡献不是端到端系统，而是逐组件诊断并修复现有 RL 算法：DAPO 用四项修复把 GRPO 从 AIME ~30 提到 50（Dynamic Sampling 单项 +8），VAPO 用七项修复让正确实现的 Actor-Critic 回到 60；Seed1.5-Thinking 在 200B 规模复现了 VAPO 的优势，Seed2.0（2026-02）没有公开后训练论文。

    报告来源

    • DAPO: DAPO: An Open-Source LLM Reinforcement Learning System at Scale, arXiv:2503.14476 (2025.03)
    • VAPO: VAPO: Efficient and Reliable Reinforcement Learning for Advanced Reasoning Tasks（Value-based Augmented PPO）, arXiv:2504.05118 (2025.04)
    • Seed1.5-Thinking: arXiv:2504.13914 (2025.04)
    • Seed-Coder: arXiv:2506.03524 (2025.06)
    • Seed2.0: 官方发布 (2026.02)，无公开 Post-Training 论文

    一、发布矩阵¶

    模型 日期 规模 AIME 分数 后训练路线
    DAPO 2025-03 -- AIME 2024 50 GRPO + 四项修复（value-free）
    VAPO 2025-04 -- AIME 2024 60 PPO + 七项修复（Actor-Critic）
    Seed1.5-Thinking 2025-04 200B / 20B MoE AIME 2024 86.7 落地 VAPO，做大规模验证
    Seed-Coder 2025-06 8B -- LongCoT RL，验证 VAPO 在代码域适用
    Seed2.0 2026-02 Pro / Lite / Mini / Code AIME 2025 98.3% 未公开，推测延续 VAPO

    二、DAPO：四个修复把 GRPO 从 30 提到 50¶

    DAPO 的出发点是"差距"而不是新算法：GRPO 在 AIME 上只有 ~30 分，而 DeepSeek 声称 79.8 分。团队逐组件诊断后定位了四个问题：

    修复 问题诊断 解决方案 AIME 增益
    Clip-Higher 对称裁剪同时压制好样本的正向强化 不对称区间：下界 \(1-\varepsilon_{\text{low}}\)、上界 \(1+\varepsilon_{\text{high}}\) +2
    Dynamic Sampling 全对/全错 query 的组内 std=0，梯度为零 丢弃并动态替换为有区分度的 query +8
    Token-Level Loss 序列级归一化使短序列 per-token 梯度更大，偏好短回答 除以总 token 数而非序列数 +1
    Overlong Reward Shaping 超长截断被硬判 0，但其实可能已接近正确 对超长但有正确信号的回答给 soft penalty 组合后 +11

    核心发现

    Dynamic Sampling 贡献最大（+8）：group 内样本完全一致时 GRPO 学不到东西，动态替换相当于把有效训练样本量接近翻倍。奖励建模与截断惩罚的设计见 1.4 奖励谱系。

    三、VAPO：让 PPO 在长 CoT 中复活¶

    标准 PPO 在长 CoT 上只有 ~5 分；VAPO 的七项修复把它提到 60（超过 DAPO 的 50），分三组：

    组 修复 作用
    Value 侧 Value-Pretraining 用 Monte Carlo return 预训练 Critic，使 RL 开始前就有合理值估计
    Value 侧 Decoupled GAE / Length-Adaptive GAE 分离值估计与优势；按序列长度调整 \(\lambda\)
    Policy 侧 Clip-Higher / Token-Level Loss 与 DAPO 相同的两项策略侧修复
    稳定性 正例 LM Loss / Group Sampling 防止 RL 偏离太远；增加组内对比
    • 消融最大项是 Value-Pretraining：去掉它 AIME 掉 49 分。随机初始化的 Critic 在 1000+ token 的 CoT 上值估计接近噪声，GAE 的优势即纯噪声，Actor 梯度方向随机。
    • 结论：Actor-Critic（60）> value-free（50）。DeepSeek-R1 放弃 PPO 是因为 671B 模型上 Critic 太贵，这是工程约束而非算法劣势；对 ≤200B 规模，Actor-Critic 仍值得投入。

    四、Seed1.5-Thinking：200B 规模验证¶

    以 Seed1.5-Thinking（200B / 20B MoE）为平台，DAPO 约 80 分、VAPO 约 86.7 分，领先 6–10 分，说明 Actor-Critic 的优势不只在小模型上成立。

    反直觉：RFT 会损害后续 RL

    在 RL 前用模型自身的正确输出做 RFT（rejection fine-tuning）短期涨点，但会收窄策略分布、压缩探索空间，降低后续 RL 的上限。最优路径是 cold-start SFT（少量高质量数据）→ 直接 RL，跳过 RFT。

    五、2026 变化¶

    • Seed2.0（2026-02）已发布 Pro / Lite / Mini / Code 四个变体，AIME 2025 达 98.3%，但没有公开后训练论文；本页方法讨论仍以 DAPO / VAPO / Seed1.5-Thinking 为准。
    • 2026 年 Seed 线没有新的 RL 算法公开，DAPO 与 VAPO 仍是引用基础，见 2.3 DAPO、2.4 VAPO。
    • 勘误：DAPO 曾被误写成 Direct Alignment from Preference Optimization is All You Need，VAPO 曾被展开成 Value-Aligned Policy Optimization，官方标题见上（VAPO = Value-based Augmented PPO）。
